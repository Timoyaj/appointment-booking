# Artifacts

What the seats report back, one file per report. Nothing here is delivered with the service; it is
the evidence the factory ran and the record of what it decided.

Conventions:

- `stage-N-<seat>-<topic>.md` — a seat's report: what it ran, the output, what it concluded.
- A claim without output is not evidence. Reports attach the run, not a summary of the run.
- Decisions that change what a stage does belong in that stage's `README.md` as well as here.
